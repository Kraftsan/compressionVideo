#  Video Compressor Bot

Telegram-бот для автоматического сжатия видеофайлов с поддержкой нескольких профилей качества. Оптимизирован для отправки в социальные сети и мессенджеры.

## ✨ Возможности

- 📹 Поддержка форматов: MP4, MOV, AVI, MKV
- 📦 Ограничение загрузки: до 20 MB
- 🎛 4 профиля качества: Low (480p), Medium (720p), High (1080p), Social Media (1080x1920 вертикальный)
- 📊 Автоматический анализ видео (длительность, разрешение, кодек, размер)
- 🧹 Автоматическая очистка временных файлов после обработки
- ⚡ Асинхронная обработка через `aiogram` и `asyncio`

## 🛠 Требования

- **Python**: 3.11 или 3.12 (рекомендуется)
- **FFmpeg**: обязательно установлен в системе и добавлен в PATH
- **Библиотеки**: `aiogram>=3.0.0`, `moviepy>=1.0.3`, `python-dotenv>=1.0.0`, `Pillow>=9.0.0`

## 🚀 Установка

1. Клонируйте репозиторий и перейдите в папку проекта:
```bash
git clone <repository-url>
cd video-compressor-bot
```

2. Создайте и активируйте виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # Linux/macOS
venv\Scripts\activate     # Windows
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Установите FFmpeg (если еще не установлен):
```bash
# Ubuntu/Debian
sudo apt update && sudo apt install ffmpeg

# macOS
brew install ffmpeg

# Windows
# Скачайте с https://ffmpeg.org/download.html и добавьте в PATH
```

## ⚙️ Настройка

1. Создайте файл `.env` в корне проекта:
```env
API_TOKEN=ваш_токен_от_BotFather
```

2. Проверьте совместимость версии Python:
```bash
python checkVersion.py
```

3. Запустите бота:
```bash
python bot.py
```

## 🎮 Использование

### Команды
- `/start` — Приветствие и инструкция
- `/help` — Подробная справка по качествам и формату

### Процесс работы
1. Отправьте видеофайл (до 20 MB) боту в чат.
2. Бот проанализирует файл и покажет информацию (размер, длительность, разрешение, кодек).
3. Выберите профиль сжатия через inline-кнопки:
   - 🔴 `Низкое (480p)`
   - 🟡 `Среднее (720p)`
   - 🟢 `Высокое (1080p)`
   - 📱 `Соцсети (Reels)` — вертикальный кроп 1080x1920
4. Получите сжатое видео с указанием процента сжатия.

## 🔧 Конфигурация (`config.py`)

| Параметр | Значение по умолчанию | Описание |
|----------|----------------------|----------|
| `BOT_TOKEN` | `"API_TOKEN"` | Токен Telegram бота из `.env` |
| `MAX_DOWNLOAD_SIZE` | `20 * 1024 * 1024` | Лимит загрузки (20 MB) |
| `MAX_UPLOAD_SIZE` | `50 * 1024 * 1024` | Лимит отправки (50 MB) |
| `COMPRESSED_QUALITY` | `"medium"` | Качество по умолчанию |

## ⚠️ Важные примечания

- 🐍 **Версия Python**: Используйте 3.11 или 3.12. Версия 3.13 может вызывать конфликты с `aiogram` и `moviepy`.
-  **FFmpeg**: Обязателен для работы `video_utils.py` и `moviepy`. Без него бот не сможет анализировать и конвертировать видео.
- 🧹 **Память**: Временные файлы хранятся в `tempfile` и автоматически удаляются после отправки результата или ошибки.
-  **Лимиты Telegram**: Если сжатый файл превышает 50 MB, бот уведомит об этом и предложит выбрать более низкое качество.
